Вариант 4, блоговая платформа. Основа — лабораторная работа №2. Интерфейс на русском, в палитре лабораторной работы №1.

## Запуск

```bash
npm install
npm run dev
```

## Глобальное состояние

Срез `filters` в `src/store/filterSlice.js` хранит активный тег (`activeTag`). Значение `null` показывает все статьи.

`TagFilter` читает тег через `useSelector` и меняет его действием `setActiveTag`. `ArticleList` подписывается на тот же тег и на клиенте оставляет только подходящие статьи. Компоненты не передают фильтр друг другу.

Лайки и текст комментария по-прежнему живут в локальном `useState` карточки.

## Компоненты

- `TagFilter` — кнопки рубрик. Активная рубрика берётся из store.
- `ArticleList` — список `ArticleCard`, отфильтрованный по `activeTag`.
- `ArticleCard` — заголовок, автор, описание, обложка, рубрика и время чтения приходят через `props`.
- `LikeButton` — счётчик в `useState`, по клику значение увеличивается.
- `CommentInput` — текст комментария в `useState`. Пустая отправка показывает ошибку.
