# ЛР2. FOLIA — React

Вариант 4, блоговая платформа. Интерфейс на русском, в палитре лабораторной работы №1.

## Запуск

```bash
npm install
npm run dev
```

## Компоненты

- `LikeButton` — счётчик в `useState`, по клику значение увеличивается. В обычном состоянии иконка и обводка `#8C4A3A`, высота 44 px.
- `CommentInput` — текст комментария в `useState`. Пустая отправка показывает ошибку. Опубликованные комментарии тоже хранятся в `useState`. Высота поля 44 px.
- `ArticleCard` — заголовок, автор, описание, обложка, рубрика и время чтения приходят через `props`. Типы проверяет PropTypes.

Внешние библиотеки состояния не используются.
